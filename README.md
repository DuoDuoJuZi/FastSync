# FastSync 用户使用说明

FastSync 是一个手机到电脑的局域网同步工具，用来把手机里的内容快速传到 Windows 电脑。

目前支持三类同步内容：

- 图片同步
- 短信同步
- 剪切板文本同步

## 注意事项

1. 手机和电脑必须在同一个局域网（同一 Wi-Fi）。
2. 电脑端需要先启动接收程序。
3. 手机端开启服务后，选择目标电脑。
4. 剪切板同步有系统限制（见下方“重要限制”）。

## 重要限制

**剪切板同步仅支持小米澎湃 OS 2（HyperOS 2）及以上系统。**

这是因为当前实现依赖小米系统特有的“传送门/内容扩展”能力。非小米系统，或低于澎湃 OS 2 的系统版本，不保证剪切板同步可用。

图片同步和短信同步不受这个小米特性限制。

## 支持平台

- 手机端：Android（项目当前配置为 Android 8.0 及以上）
- 电脑端：Windows 10 / Windows 11

## 功能说明

### 图片同步

- 手机上有新图片时会自动上传到电脑端。
- 电脑端会弹通知，你可以选择：
  - 保存到本地
  - 复制到剪切板
  - 忽略

### 短信同步

- 手机收到短信后，会把短信内容推送到电脑。
- 电脑通知支持：
  - 复制原文
  - 复制验证码（自动提取 4 到 6 位数字）

### 剪切板同步

- 手机复制文本后，电脑会收到通知。
- 你可以手动点击“复制”写入电脑剪切板。
- 请注意本功能仅在小米澎湃 OS 2 及以上可用。

## 使用步骤

### 第一步：启动电脑端

进入 `pc-receiver` 目录并运行程序，启动后会在系统托盘常驻。

### 第二步：安装并打开手机端

在 Android 设备安装 `mobile-sender` 构建出的 APK，打开应用。

### 第三步：授权权限

按应用提示授予必要权限：

- 通知权限
- 图片读取权限
- 短信权限（如果要用短信同步）
- 无障碍服务权限（尤其是剪切板同步依赖）
- 忽略电池优化（建议开启，避免服务被系统回收）

### 第四步：选择同步项

在首页勾选你需要的同步内容：

- 图片
- 剪切板
- 短信

### 第五步：选择目标电脑

在“设备”页：

- 优先使用自动发现
- 如果没找到，可手动输入电脑 IP 和端口（默认 `3000`）

### 第六步：开启服务

回到首页点击“开启服务”，看到“服务运行中”即表示成功。

## 常见问题

### 1) 手机发现不到电脑

- 确认同一 Wi-Fi
- 关闭访客网络/隔离模式
- 检查 Windows 防火墙是否放行程序和 3000 端口

### 2) 手机端服务总是掉线

- 开启忽略电池优化
- 保持前台通知常驻
- 在系统后台管理中允许自启动和后台运行

### 3) 剪切板同步无效

请按顺序检查：

1. 是否是小米设备
2. 是否为澎湃 OS 2 或更高版本
3. 无障碍服务是否已开启
4. 手机端“剪切板”同步开关是否已勾选

### 4) 收到通知但复制失败

- 检查 Windows 通知权限
- 尝试再次点击通知按钮
- 确认没有安全软件拦截剪切板写入

## 连接与隐私说明

- FastSync 设计为局域网内使用，不需要账号登录。
- 当前版本未启用端到端加密，不建议在不可信网络中使用。
- 建议仅在家庭/办公自有网络内使用。
